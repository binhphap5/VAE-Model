# VAE-Model

This project implements a Variational Autoencoder (VAE), a generative model that learns to encode input data into a latent space and then reconstruct it. Unlike standard autoencoders, VAEs introduce probabilistic sampling in the latent space, allowing for smooth interpolation and generative capabilities. The model is trained by maximizing a variational lower bound (ELBO) using the reparameterization trick for efficient gradient-based optimization.
